# Root Directory Overview

This is the root directory of the Vibroboros VS Code extension project.

## Folders

-   `.github/`: Contains GitHub-specific files like issue templates and pull request templates.
-   `.idea/`: Contains project-specific settings for JetBrains IDEs.
-   `.vscode/`: Contains VS Code-specific settings, launch configurations, and tasks.
-   `docs/`: Contains detailed documentation about the project's architecture and philosophy.
-   `media/`: Contains media assets like logos.
-   `src/`: Contains the source code for the extension.

## Key Files

-   `package.json`: Defines the project's metadata, dependencies, and scripts.
-   `extension.ts` (in `src/`): The main entry point of the VS Code extension.
-   `README.md`: The main README file for the project.
-   `PLAN.md`, `PROGRESS.md`, `TASK.md`: Files related to project planning and progress tracking.
-   `tsconfig.json`: TypeScript configuration file.
-   `esbuild.js`: Build script for the project.
-   `eslint.config.mjs`: ESLint configuration for code linting.
