# 계획: server

## 목표
공식 Model Context Protocol (MCP) SDK와 프로세스 내(in-process) 전송을 사용하여 Orchestrator 및 다른 에이전트에 풍부한 도구 세트를 제공하는 안정적인 Model Context Protocol (MCP) 서버를 구현합니다.

## 범위
- `MCPServer.ts`
- `schemas/` (MCP 요청/응답 스키마)
- `server/tools/*` (모든 MCP 도구)

## 단계
1. **도구 범위 확장**
   - 파일 I/O, 터미널, git, 웹 검색, 보안, 메모리, 린트, 브라우저 열기, 작업 완료 표시 등 핵심 환경 작업을 도구로 구현합니다.
2. **신뢰성 & 스키마 정합성**
   - 도구 입력/출력 계약이 Zod 스키마 및 MCP SDK 기대치와 일치하도록 유지합니다.
3. **성능 & 안전성**
   - 모든 도구에서 워크스페이스 경계 및 방어적 체크를 강제합니다.
4. **관측성**
   - 도구 실패와 지연 시간을 디버깅할 수 있도록 필요한 곳에 로깅을 추가합니다.
