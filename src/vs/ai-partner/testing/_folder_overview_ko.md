# 폴더: src/vs/ai-partner/testing

## 역할
이 디렉터리는 AI 파트너 서브시스템(에이전트, 서비스, Model Context Protocol (MCP) 도구, UI 통합 흐름)에 특화된 테스트를 위한 공간입니다.

## 파일 개요 (일반적인 구성)
- `UnitTests.test.ts` – 서비스, 간단한 에이전트 헬퍼, 도구 등 개별 컴포넌트에 대한 단위 테스트를 포함합니다.
- `IntegrationTests.test.ts` – UI → Orchestrator → Model Context Protocol (MCP)/A2A → UI 와 같은 전체 워크플로우를 검증하는 통합 테스트를 포함합니다.

(현재 브랜치 상태에 따라 이 파일들은 아직 스캐폴드 수준일 수 있으며, 실제 테스트 내용을 채워 넣어야 합니다.)

## AI 분석 가이드
- 에이전트, 도구, 서비스에 대한 큰 아키텍처 변경을 하기 전에 이 폴더의 테스트가 어떤 동작을 검증하고 있는지 먼저 확인하세요.
- 새로운 핵심 기능을 추가할 때는 플랜 실행, diff 적용, 도구 호출 등 엔드 투 엔드 흐름을 검증하는 테스트를 여기에 작성/갱신하세요.
