# 폴더: src/vs/ai-partner/interfaces

## 역할
이 디렉터리는 AI 파트너 서브시스템 전반에서 사용하는 핵심 TypeScript 인터페이스를 정의합니다. A2A 메시지와 코드 데이터 구조에 대한 데이터 계약(Contract)을 제공하는 곳입니다.

## 파일 개요
- `A2AMessage.ts` – Orchestrator와 전문 에이전트 사이에서 주고받는 Agent-to-Agent(A2A) 메시지 구조를 정의합니다. 확장 호스트와 A2A 서버 모두에서 사용됩니다.
- `CodeData.ts` – 코드 요약, 호출 그래프, 기타 코드 산출물 등 에이전트들이 워크스페이스를 이해할 때 공유하는 코드 관련 데이터 구조를 정의합니다.

## AI 분석 가이드
- `dispatch`를 통해 전송되는 메시지와 A2A 서버가 처리하는 메시지의 형태를 이해하려면 먼저 `A2AMessage.ts`를 읽으세요.
- 코드가 어떻게 표현되고 분석/리팩토링/문서화 에이전트 간에 전달되는지 이해하려면 `CodeData.ts`를 확인하세요.
- 새로운 공용 메시지 타입이나 데이터 페이로드를 추가할 때는 이 디렉터리의 인터페이스를 정의/확장하여 모든 에이전트와 서비스가 일관되게 사용할 수 있도록 하세요.
