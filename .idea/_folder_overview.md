# Folder: .idea

## Role

This directory contains project-specific settings for JetBrains IDEs like IntelliJ IDEA or WebStorm. These files are generally not meant to be edited manually.

## File Breakdown

-   `codeStyles/`: Contains code style settings.
-   `inspectionProfiles/`: Contains code inspection profiles.
-   `shelf/`: Contains shelved changes (temporary storage for uncommitted code).
-   `.gitignore`: Specifies files to be ignored by Git within the `.idea` directory.
-   `compiler.xml`: Compiler settings.
-   `modules.xml`: Project module definitions.
-   `vcs.xml`: Version control system settings.
-   `vibroboros.iml`: IntelliJ module file for the project.
-   `workspace.xml`: Contains workspace-specific settings like open files, run configurations, etc.

## AI Reading Guide

-   This folder is for IDE-specific configuration. It does not contain application source code.
-   You should generally ignore the contents of this folder.
