Vibroboros is a sophisticated system of specialized AI agents that collaborate as a team, right inside your IDE. It's designed to understand complex, high-level requests, formulate a detailed execution plan, and then carry out that plan using a suite of developer tools.

---

## ✨ Core Features

-   **🤖 Dynamic Task Planning & Execution:** Give Vibroboros a high-level goal (e.g., *"Refactor this class and add documentation"*) and watch as it creates and executes a step-by-step plan.
-   **✍️ Autonomous Documentation:** After completing a task, Vibroboros automatically updates its own `README.md` with the latest progress.
-   **🛠️ Full-Fledged Developer Toolset:** Includes tools for File Read/Write, Terminal Execution, Web Search, and Git Automation.
-   **🧠 Advanced Context & Long-Term Memory:** Builds a symbol index of your workspace and saves key information across sessions for better context.
-   **🚀 Proactive & Background Assistance:** Silently works in the background to perform security scans and code analysis on file saves.
-   **🧑‍🏫 Learns From Your Feedback:** Tracks your feedback on suggestions to tailor its behavior to your coding style.

## 🚀 Getting Started

### Installation

1.  Install the extension from the [Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Vibroboros.vibroboros).
2.  Open the VS Code Settings (`Ctrl+,`) and add your LLM API key in the `vibroboros.llm.apiKeys` section.

### Quick Start

1.  Open the Vibroboros icon in the Activity Bar.
2.  In the chat view, type a high-level task for your project.
3.  Review the plan generated by the `OrchestratorAgent`.
4.  Click "Execute Plan" or enable "Autonomous Mode" to let the agents work on their own.

## ⚙️ Configuration

To customize Vibroboros, open the VS Code Settings (`Ctrl+,` or `Cmd+,`) and search for "Vibroboros".

| Setting | Description | Default Value |
| :--- | :--- | :--- |
| `vibroboros.llm.apiKeys` | Your API key(s) for the LLM provider. | `[]` |
| `vibroboros.llm.endpoint` | The base URL for the OpenAI-compatible API. | `''` |
| `vibroboros.agent.{agentName}.model` | Allows specifying a different model for a particular agent. | `gpt-4` |
| `vibroboros.agent.orchestrator.contextTokenThreshold` | The token threshold at which conversation history will be automatically summarized. | `100000` |
